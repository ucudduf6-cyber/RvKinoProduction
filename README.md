# RVKINO PRODUCTION — сайт и админ-панель

Минималистичный чёрно-белый сайт кинопродакшена. Во всех разделах используется единый шрифт **Inter** (кириллица), с системным запасным шрифтом при недоступности Google Fonts. Интерфейс адаптирован для телефонов, включая формы CMS и мобильное меню. Код подходит для хранения в GitHub и запуска на сервере с **Node.js 20+**. Не требует установки npm-библиотек.

## Что внутри

- **Главная страница**: портфолио с фильтрами (фильмы, сериалы, шоу, вертикальные сериалы), описание продакшена, новости, контакты и ссылки.
- **Страница проекта**: постер, описание, участники, статус и кнопка **«Смотреть на RVKINO»**. Ссылка на просмотр разрешена только на `https://rvkino.ru` или `https://www.rvkino.ru`.
- **Админка**: малозаметная ссылка `admin` в подвале сайта; авторизация; создание, редактирование, публикация/скрытие и удаление проектов, контактов, ссылок и новостей; редактирование текстов главной страницы и описания сайта.
- **Иконки**: 34 локальных SVG в `assets/icons/` в стиле [Lucide](https://lucide.dev/) (ISC). Сайт не зависит от CDN иконок.
- **Постеры**: исходный архив изображений в `assets/posters/`; они **не опубликованы автоматически**, поскольку соответствие IMDb не подтверждено. Новые постеры загружаются через админку.

## Быстрый запуск на компьютере или VPS

```bash
# 1. Установите Node.js 20 или новее
node -v

# 2. Перейдите в каталог сайта
cd rvkino-production

# 3. Настройте логин и пароль администратора (только один раз)
npm run setup

# 4. Запустите сервер
npm start
```

По умолчанию сайт доступен на `http://127.0.0.1:3000`. Откройте `http://127.0.0.1:3000/admin.html` или нажмите маленькую ссылку `admin` внизу главной страницы.

**Пароль никогда не хранится в HTML, JavaScript или GitHub.** Команда `npm run setup` создаёт `.env` с солью и хэшем scrypt. `.env` включён в `.gitignore`. Если у вас уже есть `.env`, **не удаляйте его без резервной копии**.

## Как пользоваться админкой

| Раздел | Что можно сделать |
|---|---|
| Обзор | Посмотреть статистику и быстро добавить проект/новость |
| Проекты | Добавить фильм/сериал/шоу/вертикальный сериал, постер, год, описание, IMDb и ссылку просмотра; опубликовать или скрыть |
| О сайте | Изменить название сайта, метаописание, заголовки и описания главной страницы, текст о продакшене и блок контактов |
| Контакты | Добавить, изменить, скрыть или удалить Telegram, почту, телефон и другие способы связи |
| Ссылки | Управлять ссылками на соцсети, онлайн-кинотеатр и внешние сайты |
| Новости | Создавать новости, менять дату, анонс и полный текст, указывать внешнюю ссылку, публиковать или сохранять черновик |

Контакты поддерживают `https://`, `mailto:` и `tel:`. Обычные внешние ссылки и ссылки новостей — только `https://`. Тексты отображаются безопасно, без выполнения HTML-кода.

**Новости:** если указать полный текст, но не указывать внешнюю ссылку, новость открывается на сайте во всплывающем окне. Если указана внешняя ссылка, кнопка ведёт на неё.

## Где хранятся данные

- `data/projects.json` — проекты;
- `data/site.json` — тексты сайта, контакты, ссылки и новости;
- `assets/posters/uploads/` — загруженные через админку постеры;
- `.env` — параметры сервера и хэш пароля.

Эти каталоги/файлы **не нужно публиковать в GitHub**. Они исключены из Git. При обновлении кода не перезаписывайте и не удаляйте `data/`, `assets/posters/uploads/` и `.env`. Делайте резервные копии этих данных.

## Публикация через GitHub

1. Создайте репозиторий и загрузите **содержимое** папки `rvkino-production`.
2. На своём VPS клонируйте репозиторий, запустите `npm run setup` и `npm start`.
3. Для постоянной работы используйте systemd/PM2 и настройте HTTPS через Nginx или Caddy. Пример конфигурации systemd и Nginx лежит в `deploy/`.
4. Если Nginx завершает HTTPS и проксирует на Node.js, настройте `TRUST_PROXY=1` в `.env`. Передавайте `X-Forwarded-Proto` и `Host` из доверенного Nginx. Не открывайте Node.js напрямую в интернет, когда `TRUST_PROXY=1`.
5. После публикации убедитесь, что `/api/admin/session` работает, а `/data/site.json` и `/.env` недоступны извне.

**Важно:** GitHub Pages — статический хостинг. Он **не может запустить эту админку** и сохранять изменения. Для работающей CMS нужен Node.js-сервер или другой серверный хостинг. GitHub здесь служит репозиторием исходного кода.

## Тесты

```bash
npm test
```

Проверяются авторизация, защита от неавторизованных изменений, CRUD проектов и страниц, фильтрация черновиков, проверка ссылок и загрузка постеров.

## Структура

```text
rvkino-production/
  index.html           # главная
  project.html         # страница проекта
  admin.html           # интерфейс управления
  style.css            # общий дизайн
  script.js            # главная: проекты, новости, контакты
  detail.js            # страница проекта
  admin.js             # админ-панель
  shared.js            # общие функции
  server.js            # Node.js HTTP API и статика
  setup-admin.js       # безопасная первичная настройка пароля
  assets/
    logo.png           # обрезанная по содержимому копия оригинального логотипа
    logo-original.png  # оригинальный файл пользователя
    icons/              # локальные SVG
    posters/            # постеры из архива
  deploy/               # примеры для VPS
  tests/                # автотесты
```

## Безопасность

Админка защищена серверной авторизацией, HttpOnly cookie с SameSite=Strict, CSRF-токеном, ограничением числа попыток входа и валидацией данных. Используйте HTTPS на публичном домене. Ссылка `admin` намеренно малозаметна, **но скрытая кнопка сама по себе не является защитой**. Защита обеспечивается серверной авторизацией.

Если пароль когда-либо был опубликован или отправлен в открытом сообщении, **смените его перед публикацией сайта**. Для смены: остановите сервер, сохраните резервную копию `.env`, удалите старый `.env`, повторно выполните `npm run setup` и перезапустите сервер.

## Мобильный дизайн и шрифты (обновление)

- Новый единый шрифт **Inter** (Google Fonts) используется на главной, в карточках проектов, новостях, описаниях и админке. При недоступности сервиса загружается системный шрифт.
- Адаптивная сетка на 320–760 px, горизонтальная прокрутка категорий, удобное мобильное меню, полноширинные кнопки просмотра, увеличенные зоны нажатия.
- В редакторе проекта и админке поля ввода на iPhone используют шрифт 16 px без автоматического приближения, меню разделов закрывается по фону или Esc, окна редакторов занимают высоту экрана телефона.
- Все изменения дизайна находятся в `style.css`, логика мобильной навигации — в `script.js`, `detail.js` и `admin.js`.
- Для работы Google Fonts нужен доступ к `fonts.googleapis.com` / `fonts.gstatic.com`; эти домены разрешены в серверном CSP.
